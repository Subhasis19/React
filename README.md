# React

## What is React?
React is a JavaScript libary for bulding user interface ,especially for web application where content changes dynamically without reloading the page .    mainly for singlepage application (SPA). it was developed by Facebook. 

## Key Features 
- Component based architecture (reuable UI blocks)
- Virtual DOM for fast rendering 
- JSX (HTML Like syntax inside js)

- Fast and efficent updates 
- Reusable componets -> clear code
